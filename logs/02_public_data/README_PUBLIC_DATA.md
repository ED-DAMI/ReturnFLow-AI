# Donnees publiques utiles

Le dossier ne redistribue pas automatiquement les gros datasets externes. Les telecharger depuis leurs pages d'origine permet de conserver la licence et la provenance.

## Produits SHEIN
https://github.com/luminati-io/Shein-dataset-samples/blob/main/shein-products.csv

Utilisation conseillee:
- product_id / model_number
- category
- color
- size / all_available_sizes
- description
- other_attributes
- top_reviews

## ShoppingAppReviews
https://data.mendeley.com/datasets/chr5b94c6y/2

Filtrer la partie SHEIN si vous souhaitez analyser du texte client reel sur l'application.
