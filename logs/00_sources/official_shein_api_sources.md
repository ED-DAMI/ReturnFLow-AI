# Sources officielles SHEIN - retours et apres-vente

Ces liens sont les sources de reference pour reconstruire un event log academique realiste. Ils ne donnent pas acces aux logs internes clients sans autorisation API.

## API retours

- Catalogue API retours: https://open.sheincorp.com/documents/apidoc/2000004
- Liste des retours: https://open.sheincorp.com/documents/apidoc/detail/3001281
- Details d'un retour: https://open.sheincorp.com/documents/apidoc/detail/3001282-2000004
- Nouvelle liste apres-vente: https://open.sheincorp.com/documents/apidoc/detail/3002061
- Machine d'etats apres-vente: https://open.sheincorp.com/documents/system/f7b0b584-28d2-4b9f-a5b8-55dca5ba4056

## Points utiles pour ReturnFlow AI

Les APIs officielles exposent notamment des identifiants de retour, numeros de commande, statuts, dates de demande et de mise a jour, donnees logistiques, informations produit et timestamps de reception/achevement.

Le corpus synthetique du dossier `03_synthetic_event_logs/` s'inspire de cette structure, mais ne constitue pas une copie de logs internes SHEIN.
